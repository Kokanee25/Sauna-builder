# 01 — Planning & Site Selection

Decisions here drive every later number. Spend time on this page.

## 1. Indoor vs. outdoor

| Factor | Indoor (basement, garage, spare room) | Outdoor (shed, standalone cabin) |
|--------|----------------------------------------|----------------------------------|
| Foundation | Existing floor | Need slab/pier foundation |
| Weatherproofing | None extra | Full exterior envelope + roof |
| Heater | Electric usually simplest | Electric (run a circuit) or wood |
| Permits | Electrical; sometimes none for interior | Structure + electrical + sometimes zoning |
| Cost | Lower | Higher |
| This blueprint's default | ✅ Reference build is indoor electric | Notes provided where they differ |

**Reference build = indoor electric**, sited in a garage corner or basement.

## 2. Choosing the location

Checklist for the spot:

- [ ] **Floor can get warm/damp.** Concrete, tile, or sealed floor is ideal.
      Avoid finished hardwood directly under the sauna.
- [ ] **Drainage / water tolerance.** A floor drain is a luxury, not required for
      a dry sauna, but the floor must tolerate the occasional splash and mopping.
- [ ] **Electrical access.** Can you reach the main panel to add a 240 V circuit?
      (See [`docs/07-electrical.md`](07-electrical.md).) Long runs cost more.
- [ ] **Outside wall nearby** for ventilation/exhaust if possible.
- [ ] **Ceiling height ≥ 7 ft (2.1 m).** Lower wastes the hot upper layer;
      higher wastes energy.
- [ ] **Clearance to combustibles** around heater and (for wood) chimney route.
- [ ] **Egress.** Door must swing **outward** and never be lockable from outside.

## 3. Budget bands (materials only, reference 6×5 ft build)

These are rough North American ranges to plan with — verify locally.

| Tier | Approx. materials cost | What you get |
|------|------------------------|--------------|
| Budget | $1,800 – $2,800 | SPF framing, basic cedar/hemlock T&G, entry electric heater |
| Mid | $3,000 – $5,000 | Clear cedar throughout, quality 6 kW heater + digital control, glass door |
| Premium | $5,500 – $9,000+ | Premium cedar/aspen/alder, full-glass front, premium heater, lighting |

Add electrician labor (typically $400–$1,200 for a dedicated circuit) and any
permit fees. Full itemized list in [`docs/03-materials-bom.md`](03-materials-bom.md).

## 4. Permits — figure this out *before* buying

Typical requirements (varies widely by jurisdiction):

- **Electrical permit + inspection** for the new 240 V circuit. Nearly always
  required; do not skip.
- **Building permit** if you alter the structure, add a standalone outbuilding,
  or it exceeds a size threshold.
- **Chimney/solid-fuel approval** for a wood heater.
- **Setback/zoning** for outdoor structures near property lines.

Call your local building department, describe the project, and ask exactly which
permits apply. Get it in writing if you can. See
[`docs/09-safety-and-codes.md`](09-safety-and-codes.md).

## 5. Lead-time planning

Long-lead items to order early:

- Sauna heater + control unit (can be weeks)
- Sauna door (glass or wood, pre-hung)
- Specialty cedar/aspen paneling if not stocked locally

## Output of this step

By the end of planning you should have:

1. A chosen, measured location with confirmed ceiling height.
2. A decided heater type (electric for the reference build).
3. A confirmed list of required permits.
4. A target budget tier.

Carry the measured interior space into the next doc.
