# 11 — Build Sequence & Master Checklist

The whole build in order. Print this page and tick boxes on site. Each phase
links to its detailed doc.

## Phase 0 — Plan & permit ([`01`](01-planning.md), [`02`](02-design-and-dimensions.md))

- [ ] Location chosen, measured; ceiling height ≥ 7 ft confirmed
- [ ] Interior dimensions finalized; volume computed
- [ ] Capacity and bench layout decided
- [ ] Heater type chosen (electric reference); kW computed ([`06`](06-heater-sizing.md))
- [ ] Budget tier set
- [ ] Building department called; required permits identified
- [ ] Long-lead items ordered (heater, controller, door, specialty wood)

## Phase 1 — Materials ([`03`](03-materials-bom.md))

- [ ] Full BOM ordered with waste allowance
- [ ] Framing lumber (KD-SPF), PT bottom plate
- [ ] Mineral wool (R-13 walls, R-21+ ceiling)
- [ ] Aluminum foil vapor barrier + foil tape
- [ ] Cedar T&G (walls + ceiling), furring, trim
- [ ] Clear cedar/aspen for benches/backrests
- [ ] Heater, controller, stones, guard rail
- [ ] Door, light fixture, thermometer/hygrometer, duckboard, bucket+ladle
- [ ] Stainless fasteners, sealant
- [ ] Tools + PPE on hand

## Phase 2 — Framing ([`04`](04-framing.md))

- [ ] Floor base prepared (sealed concrete/tile + drainage if any)
- [ ] PT bottom plate with capillary break on concrete
- [ ] Walls framed, 16 in OC, plumb; room square (equal diagonals)
- [ ] Backing added for benches, heater, guard, light, controls
- [ ] Ceiling framed at 7 ft, deep cavity
- [ ] Door rough opening sized to door unit; outswing confirmed
- [ ] Vent openings framed (intake low near heater; exhaust opposite)

## Phase 3 — Electrical rough-in ([`07`](07-electrical.md))

- [ ] Electrician runs dedicated 240 V heater feed to location
- [ ] Sensor cable and light cable run; boxes set; service loops left
- [ ] **Rough-in inspection passed**

## Phase 4 — Insulation & vapor barrier ([`05`](05-insulation-vapor-barrier.md))

- [ ] All wall cavities filled (R-13), no gaps/compression
- [ ] Ceiling insulated R-21+
- [ ] Foil vapor barrier, foil facing room, continuous walls + ceiling
- [ ] All seams overlapped + foil-taped; ceiling laps over walls
- [ ] Every penetration sealed (wires, vents, sensor)
- [ ] Furring strips installed for air gap

## Phase 5 — Ventilation ([`08`](08-ventilation.md))

- [ ] Intake fitted low, near/under heater
- [ ] Exhaust fitted opposite, with adjustable wooden slider
- [ ] Drying-vent scheme in place
- [ ] Barrier sealed around vent sleeves; wooden trim

## Phase 6 — Paneling ([`10`](10-interior-finishing.md))

- [ ] Wood acclimated
- [ ] Ceiling paneled first
- [ ] Walls paneled, blind-nailed stainless, expansion gaps
- [ ] Trim/corners cut and fitted

## Phase 7 — Benches & woodwork ([`10`](10-interior-finishing.md))

- [ ] Bench supports anchored to backing
- [ ] Upper bench 36 in, lower 18 in; slats spaced; edges eased
- [ ] Fasteners countersunk + plugged (stainless)
- [ ] Backrests/headrests mounted off wall
- [ ] Open space under lower bench

## Phase 8 — Heater, controls & final electrical ([`06`](06-heater-sizing.md), [`07`](07-electrical.md))

- [ ] Heater mounted at spec height with all clearances
- [ ] Stones rinsed and loosely stacked to spec weight
- [ ] Guard rail installed
- [ ] Controller mounted; sensor placed exactly per manual
- [ ] Heater leads connected (high-temp); junctions outside
- [ ] Sauna-rated light + guard installed; switch outside
- [ ] **Final electrical inspection passed**

## Phase 9 — Door & accessories ([`10`](10-interior-finishing.md))

- [ ] Outswing door hung, ball-catch (no lock), wood handles
- [ ] Under-door vent gap maintained
- [ ] Thermometer/hygrometer mounted
- [ ] Duckboard, bucket, ladle placed
- [ ] Operating-rules sign posted ([`09`](09-safety-and-codes.md))

## Phase 10 — Commission ([`12`](12-maintenance.md))

- [ ] First heat/cure cycle run with ventilation open (no water on stones first)
- [ ] Check for hot spots, smells, odd noises; verify controller/sensor accuracy
- [ ] Verify temperature reaches target (≈ 175–195 °F upper bench)
- [ ] Test löyly (water on stones) once cured
- [ ] Confirm room dries fully after first session
- [ ] All permits/inspections closed out

## Final safety sign-off ([`09`](09-safety-and-codes.md))

- [ ] Door swings out, openable from inside, tempered glass
- [ ] Heater clearances + guard verified
- [ ] GFCI + inspections complete
- [ ] No plastic / no varnish / no resinous wood in hot room
- [ ] Edges eased, fasteners plugged, handrails fitted
- [ ] Ventilation works (heats evenly, dries after use)
